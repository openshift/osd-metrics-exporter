# osd-metrics-exporter AGENTS.md

## What this is

A controller-runtime operator that runs on OpenShift Dedicated clusters and exports Prometheus gauges about cluster feature usage (identity providers, cluster-admin, limited support, cluster proxy + CA validity, cluster ID, CPMS state, pull-secret validity, pods blocking node drain). It does not reconcile any CRDs of its own; controllers only watch existing cluster resources and update metrics.

## Commands

The `Makefile` just includes OSD boilerplate (`boilerplate/generated-includes.mk` → `boilerplate/openshift/golang-osd-operator/standard.mk`). Do not edit files under `boilerplate/` by hand; they are replaced by `make boilerplate-update`.

- Build: `make go-build` → `build/_output/bin/osd-metrics-exporter` (FIPS is enabled; `fips.go` is generated by `ensure-fips`)
- Lint: `make go-check` (golangci-lint with `boilerplate/openshift/golang-osd-operator/golangci.yml`); `make lint` also validates `deploy/` YAML
- Unit tests: `make test` (downloads envtest assets for linux/amd64; excludes `test/e2e`). On a dev machine plain `go test ./controllers/... ./pkg/...` works, since the unit tests use the controller-runtime fake client.
- Single test: `go test ./controllers/group -run TestReconcileGroup_Reconcile/single_user`
- Pre-commit: `pre-commit run` (golangci-lint, `go build ./...`, `go mod tidy` drift check, gitleaks, YAML checks on `deploy/`, RBAC wildcard check). Don't bypass hooks with `--no-verify`.
- E2E (needs a real cluster; build tags `osde2e,e2e`):
  ```
  cd test/e2e
  export OCM_TOKEN=$(ocm token) OCM_CLUSTER_ID=<cluster-id>
  DISABLE_JUNIT_REPORT=true ginkgo run --tags=osde2e,e2e --procs 4 --flake-attempts 3 --trace -vv .
  ```

For running locally against a cluster without OLM (creating namespace/RBAC, logging in as the service account), follow the steps in `README.md`.

## Architecture

- `main.go` builds the manager, reads the cluster ID from the `ClusterVersion/version` resource, registers each controller, and starts the metrics server via `operator-custom-metrics` on port 8383 (`/metrics`, with a ServiceMonitor). controller-runtime's own metrics server is disabled.
- The manager cache is restricted to `openshift-osd-metrics`, `openshift-config` and `openshift-machine-api` (Secrets only from `openshift-config`). A controller that watches namespaced objects elsewhere needs both a cache change here and new RBAC.
- The CPMS controller is registered only if the `controlplanemachinesets.machine.openshift.io/v1` API exists (discovery check), so older clusters or those without CPMS still work.
- `pkg/metrics`: `AdoptionMetricsAggregator` owns every gauge. `GetMetricsAggregator(clusterId)` returns a process-wide singleton that all controllers share. Controllers call `Set*`/`Reset*` methods on it rather than touching Prometheus directly. The IDP gauge is recomputed by a ticker (`Run()`, every minute) from an internal map. Other gauges are set directly, often `Reset()` first so stale label combinations are dropped. Tests build their own aggregator with `metrics.NewMetricsAggregator(...)` and assert with `prometheus/testutil`.
- `controllers/<name>/`: one reconciler per metric source. Most filter events with `predicate.Funcs` down to one named object (e.g. the `cluster-admins` Group) and some add a finalizer so they can zero the metric on delete. `controllers/utils` has the small requeue/contains helpers.

To add a metric: add the gauge and its setter to `pkg/metrics/metrics.go`, include it in `GetMetrics()`, write the controller and register it in `main.go`, add scheme registration if it's a new API group, then update RBAC (below).

## Deployment manifests / RBAC

The same RBAC exists in several places, and a permission change usually has to be made in each:
- `deploy/` (OLM bundle/CSV input)
- `deploy_pko/` (Package Operator manifests; `manifest.yaml` plus `*.gotmpl` templates, and a cleanup Job for OLM→PKO migration)
- `resources/` (openshift-config Role/RoleBinding)
- `hack/olm-registry/olm-artifacts-template.yaml` (SelectorSyncSet with Namespace/Roles, CatalogSource, Subscription)
- `hack/pko/clusterpackage.yaml`

Keep RBAC least-privilege with explicit verbs/resources; the pre-commit hook flags wildcards in `deploy/`.
